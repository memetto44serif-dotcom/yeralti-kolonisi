# Yeraltı Kolonisi — Karınca İmparatorluğu

Tarayıcıda çalışan yeraltı karınca RTS'i. Kurulum yok: `index.html` dosyasını açman yeterli.

- 4 kaynak (yiyecek, lif, mineral, bal şebnemi), 4 çağ, 13 karınca kastı, 14 oda, 20 teknoloji
- Kazarak harita yaratma, düşman koloni yapay zekâsı, yaban hayatı, gün/gece · yağmur · kış

**Kontroller:** Sol tık/sürükle seç · Sağ tık git–saldır–kaz · Sağ tık sürükle alan kazma ·
`B` inşa · `Y` Kraliçe Odası (çağ) · `WASD` kamera · tekerlek zoom · `F` hız · `P` duraklat
